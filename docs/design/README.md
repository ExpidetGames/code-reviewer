# App design board

`index.html` is a reading copy of the design of the code-review.com app: the design system and every screen, in the look of the landing page (`code-review.com` repository, `src/app/globals.css`). It is one file. Open it in a browser; no build, server or install is needed.

- **For whom:** people who do not read code. Each screen has a short description, its address in the app, who can see it and the file that renders it.
- **Status:** matches the app at the commit named on the page. The screens are mockups with sample data; nothing is saved.
- **Themes:** Light, Dark and Auto (system) with the switch at the top left.
- **Fonts:** Geist loads from Google Fonts. Offline, the system font is used.
- **Not the app:** the app still uses its shadcn look. This page is the target, not what is built.

The screens were drawn on a Claude design board. The page is a snapshot of it; when the app gets a new screen, the page needs a new snapshot.
